# 本文の書き方（richtext）の仕様

固定ページ等の本文に使う、書き方を絞ったMarkdownの正本。キットのコード（`internal/web/richtext`）が、この規則で本文を**構造**（ブロックと文字の並び）に読み、`components.html` の部品が `html/template` で描く。HTMLの文字列は組み立てず、`template.HTML` は使わない。経緯は [pages-plan.md](pages-plan.md) の3節。

## 1. 前提

- 本文は保存の前に `form.Text` を通す（CRLFをLFに揃え、改行・タブ以外の制御文字を拒否し、UTF-8を検証する）。読む処理はLFだけを前提にする。
- 「文字」は rune で数える。本文は5万文字まで。
- 読む処理は、同じ入力から同じ構造を返す純粋な関数 `Parse(body) (Doc, error)`。エラーは上限（表の列・行）を超えたときだけで、書き方の誤りはエラーにせず、文字として出す。

## 2. 行の種類を決める順番

本文を行に分け、上から1行ずつ、**生の行のまま**（`\` を見る前に）種類を決める。行末の空白は無視する。

| 順 | 条件 | 種類 | 今のブロック |
|---|---|---|---|
| 1 | 空行（空白だけを含む） | — | 閉じる |
| 2 | `## ` か `### ` で始まり、その後に空白以外の文字がある | 見出し（h2・h3） | 閉じる |
| 3 | `表: ` で始まり、次の行が表の開始（順4） | 表の説明 | 閉じる |
| 4 | `\|` で始まり、次の行が区切り行 | 表の見出しの行 | 閉じる |
| 5 | 表の途中で、`\|` で始まる | 表の行 | 続く |
| 6 | `- ` で始まり、その後に空白以外の文字がある | 箇条書きの項目 | 箇条書きでなければ閉じる |
| 7 | 1〜9桁の数字＋`. ` で始まり、その後に空白以外の文字がある | 番号付きの項目 | 番号付きでなければ閉じる |
| 8 | それ以外 | 段落の行 | 段落でなければ閉じる |

- 段落の途中でも、順2〜7に当たる行は新しいブロックを始める。
- `#`・`####` 以上・`##`（後ろが空）・行頭に空白がある行（`  - x`）は、段落の行。
- 番号付きの数字の値は使わない（`ol` の順で出す）。
- 項目は1行だけ。項目の次の行が順6・7に当たらなければ、リストを閉じて段落等になる（項目の折り返しは書けない）。
- 段落の行は、ブロックの中で改行（`br`）でつなぐ。

## 3. 表

- **区切り行**: `|` で分けた各セル（前後の空白を除く）が、`:` を前後に0〜1個付けた `-` 3個以上（`---`・`:---`・`---:`・`:---:`）で、セルの数が見出しの行と同じ。並びの指定（`:`）は使わない。
- **列の分け方**: 行を「`\` の付いていない `|`」で分ける。先頭と末尾の `|` は外す。各セルの前後の空白を除いてから、セルを文字の並び（4節）として読む。セルの中で `\|` と書けば `|` を出せる。
- 列の数は見出しの行で決まる。行のセルが少なければ空のセルで埋め、多ければ余りを捨てる。
- 表は、`|` で始まる行が続く間続く。
- **説明（caption）**: 表の直前の行に `表: 説明` があれば、`表: ` の後ろの文字（前後の空白を除く。文字の並びとしては読まず、そのまま文字で出す）を説明にする。無ければ「表N（直前の見出し）」、見出しが無ければ「表N」。Nは本文の中の表の順（1から）。直前の見出しは、その表より前で最後に出た見出しの文字（強調・リンクの記号を除いた文字）。
- 上限: 20列・200行（見出しの行を含めない）。超えたら `Parse` がエラーを返す。
- 見出しの行のセルは `th scope="col"`、それ以外は `td`。

## 4. 文字の並び（見出し・段落の行・項目・セルの中）

左から1文字ずつ読む。

| 書き方 | 出力 | 規則 |
|---|---|---|
| `\` ＋ `\ * [ ] ( ) \| # - . :` のどれか | その記号の文字 | 他の文字の前の `\` は、`\` の文字として残す |
| `**文字**` | 強調 | 次の `\` の付いていない `**` までが中身。中身が空、または閉じる `**` が無ければ、`**` は文字。中身は文字だけ（`\` の処理はする。リンク・入れ子は扱わない） |
| `[文字](URL)` | リンク | `[` から、`\` の付いていない次の `]` までが文字。その直後が `(` で、次の `)` までがURL。文字が空、URLに空白がある、`)` が無い、URLが5節の許可に当たらない場合は、`[` は文字（以降はそのまま読み続ける）。文字の中は文字だけ（強調は扱わない） |
| それ以外 | 文字 | |

- 閉じる記号の探索は、同じ文字の並び（1行・1セル）の中だけ。
- **速さ**: 閉じる記号が見つからなかったら、その並びでは同じ記号を以降探さない（`**` や `[` が多数あっても、読む時間が入力の長さに比例する）。

## 5. リンクのURL

| 種類 | 許可の条件 | 出力 |
|---|---|---|
| 外部 | `net/url` で解析でき、スキームを小文字にして `https`、ホストが空でない、ユーザー情報が無い | `a href`（同じタブ） |
| サイト内 | `/` で始まり、`//` と `/\` で始まらない | `a href` |

- どちらも、空白・制御文字・`\` を含まないこと（`NavLinks` の検査と揃える）。
- 許可しないURL（`http://`・`mailto:`・`javascript:`・`data:`・`//example.com`・`/\example.com`・`HTTPS://user@example.com` 等）は、`[文字](URL)` をそのまま文字として出す。

## 6. 例（テストの表と同じもの）

| 入力 | 構造 |
|---|---|
| `## 会社概要` | 見出しh2「会社概要」 |
| `##会社概要` | 段落「##会社概要」 |
| `# 大見出し` | 段落「# 大見出し」 |
| `\## 見出しではない` | 段落「## 見出しではない」 |
| `一行目`⏎`二行目` | 段落（「一行目」改行「二行目」） |
| `本文`⏎`## 見出し` | 段落「本文」、見出しh2「見出し」 |
| `- りんご`⏎`- みかん` | 箇条書き（2項目） |
| `- りんご`⏎`続き` | 箇条書き（1項目）、段落「続き」 |
| `  - 字下げ` | 段落「  - 字下げ」 |
| `3. 三`⏎`7. 七` | 番号付き（2項目） |
| `- `（後ろが空） | 段落「-」 |
| `\| 項目 \| 内容 \|`⏎`\|---\|---\|`⏎`\| 社名 \| 例 \|` | 表（見出し2列、1行）、説明「表1」 |
| `\| a \| b \|`⏎`\| c \| d \|` | 段落（区切り行が無いため） |
| `表: 会社の情報`⏎（上の表） | 表の説明「会社の情報」 |
| `\| a\|b \| c \|`⏎`\|---\|---\|` | 見出し「a\|b」「c」 |
| `**重要**` | 強調「重要」 |
| `**閉じない` | 文字「**閉じない」 |
| `****` | 文字「****」 |
| `[会社](/about)` | リンク（サイト内） |
| `[外部](https://example.com)` | リンク（外部） |
| `[危険](javascript:alert(1))` | 文字のまま |
| `[古い](http://example.com)` | 文字のまま |
| `[空白](/a b)` | 文字のまま |
| `[](/about)` | 文字のまま |
| `[**強調**](/about)` | リンク、文字「**強調**」（強調は扱わない） |
| `**[リンク](/about)**` | 強調「[リンク](/about)」（リンクは扱わない） |
| `\[文字\](/about)` | 文字「[文字](/about)」 |
| `<script>` | 文字「<script>」（描くときにエスケープされる） |
