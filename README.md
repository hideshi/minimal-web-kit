# minimal-web-kit

個人情報の取得と外部依存ライブラリを最小限に抑え、安全で身軽なWebアプリを手早く作れる「Go実装のひな形 ＋ 少数のAIスキル」です。

---

## 特徴

- **完全クリーンな初期状態**:
  リポジトリをクローンした直後は、サンプルの残骸が一切ない純粋な「クリーン基盤（Base）」です。消す手間や消し忘れのリスクがありません。
- **個人情報の非取得**:
  氏名・メールアドレス・電話番号・パスワードは一切要求しません。ブラウザ単位の実名不要なセッション（OwnerID）のみで完結します。
- **依存ゼロ・単一バイナリ**:
  Go 1.25+ の標準機能（`net/http`、`html/template`、`embed.FS`、`log/slog`）を中心に構成。フロントエンドビルド（Node.js/npm）を排除し、外部サービスなしで即座に起動します。
- **デジタル庁デザインにインスパイアされた機能的UI**:
  派手な装飾を排し、高いコントラスト比、明瞭なフォーカスインジケータ、セマンティックなHTML構造によるアクセシブルな自前CSS 1本を同梱。
- **データ保護・ログ契約**:
  機密情報や接続元IP、User-Agentをログに出力しません。セッショントークンのハッシュ保存、データ即時破棄機能を標準搭載。
- **規約はスキルに、強制はテストに**:
  3本の軽量なAIスキル（計画・実装・検証）と、依存関係やデータ台帳の逸脱を検知する機械的テストを同梱。

## 起動方法

### 前提
- Go 1.25 以上

### 実行
```bash
# クローンと起動（クリーン基盤）
git clone <repository-url>
cd minimal-web-kit
go run ./cmd/server
```
ブラウザで `http://127.0.0.1:8080` にアクセスしてください。

### サンプル機能（プライベートメモ）を試す
生きた実装例や手本としてメモアプリを動かしたい場合は、ワンコマンドで追加できます：
```bash
# メモ機能の適用
make add-memo

# 起動
go run ./cmd/server

# 再びクリーン基盤に戻す
make clean-base
```

### テスト実行
```bash
go test -race -v ./...
```

## プロジェクト構成

```
.
├── AGENTS.md               # 開発規約・承認必須境界・コミット規約
├── DATA.md                 # 永続化データ台帳（テストで整合性を検証）
├── Makefile                # ビルド・テスト・テンプレート管理コマンド
├── cmd/
│   ├── server/             # 起動エントリーポイント
│   └── kit/                # テンプレート適用・クリーン復元ツール
├── internal/
│   ├── app/                # アプリケーション初期化・サーバー管理
│   ├── domain/             # ドメイン型・セッション定義
│   ├── store/              # 永続化インターフェース・SQLite・メモリ実装・マイグレーション
│   └── web/                # HTTPハンドラ・ミドルウェア・テンプレート・CSS
├── templates/              # 追加可能な用途別テンプレート（memo等）
├── skills/                 # AIペアプログラミング用スキル（各150行以内）
│   ├── plan-and-select/    # 計画・依存とデータの最小化判定
│   ├── implement-and-change/# 実装・標準機能での既定解と変更手順
│   └── verify-and-audit/   # 検証・機械的テストと監査
└── test/                   # 機械的強制テスト（依存、テンプレート、DATA.md、カナリア）
```
